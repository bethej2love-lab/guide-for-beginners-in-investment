# 📘 S&P500 ETF 얼렁뚱땅 가이드

처음 투자를 시작하는 분들을 위한 S&P500 ETF 입문 가이드입니다.

**[→ 바로 사용하기](https://bethej2love-lab.github.io/guide-for-beginners-in-investment/)**

## 주요 기능

- ETF 기초 개념 설명 (ETF란, 복리, 배당, 환율, 세금 등)
- 대표 S&P500 ETF 비교 (미국/한국 상장)
- 10년·30년 적립식 투자 시뮬레이터
- 나만의 경제적 자유 달성 시기 계산기 (Chart.js 시각화)
- S&P500 30년·5년·1년 수익률 참고 차트
- 실시간 히트맵 연결 (Finviz)
- 주제별 관심사 투표 (카운트 API 연동)
- 방문자 수·유용해요 카운트
- 다크모드 지원 / 카카오톡·링크 공유

## 기술 스택

Vanilla HTML/CSS/JS · Chart.js · CountAPI · GitHub Pages
